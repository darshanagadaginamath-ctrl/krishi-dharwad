# 🌾 Dharwad Krishi Plan - Agricultural & Mandi Intelligence

> **Comprehensive Agricultural Planning, Mandi Price Analytics & 3D Decision Platform for Dharwad District, Karnataka, India.**
> Validated with **University of Agricultural Sciences, Dharwad (UASD)** Package of Practices & **AGMARKNET / e-NAM** official APMC market rates.

---

## 🌟 Key Features

1. **3D Farmland & Agronomic Studio (Three.js)**
   - 8 interactive procedural visual modes: Dharwad Farmland Landscape, Soil Horizon Profile (Deep Vertisol vs Red Alfisol), 5-Stage Plant Morphology, Subsurface Root & Moisture Zones, Precision Micro-Drip Irrigation, Pest & IPM Inspection, Harvest & Warehouse Storage, and 3D Financial Comparison Pillars.
2. **Official Mandi Market Intelligence & Crop Economics**
   - Covers 9 major crops: Bt Cotton, Soybean, Hybrid Maize, Rabi Jowar (Maldandi), Bengal Gram (Chickpea), Groundnut, Red Onion, Byadgi Dry Chilli, and Guava Horticulture.
   - Verified dated APMC Mandi rates from Hubballi, Annigeri, and Dharwad with MSP benchmarks, yields, cultivation costs, gross income, net profits, and break-even prices per quintal.
3. **Top 3 Crop Rankings (Rain-fed vs Irrigated)**
   - Distinct agronomic scoring and rankings for rainfed holdings (Bengal Gram #1, Soybean #2, Rabi Jowar #3) and irrigated holdings (Bt Cotton with drip #1, Guava/Chilli #2, Hybrid Maize #3).
4. **Interactive Farm Budget & Break-Even Simulator**
   - Real-time scaling for any farm size (1 Acre, 2 Acres, 3 Acres, 5 Acres, etc.) with custom yield, price, and itemized input expense adjustments.
5. **Karnataka Season-Wise Sowing & Harvesting Schedule**
   - Full statewide and district-level seasonal matrix covering Kharif (ಮುಂಗಾರು), Rabi (ಹಿಂಗಾರು), Summer (ಬೇಸಿಗೆ), and Perennial (ಬಹುವಾರ್ಷಿಕ) cycles.
   - Month-by-month interactive explorer with visual maturity cues and double-cropping rotations.
6. **Bilingual Accessibility**
   - Seamless one-click toggle between English and **ಕನ್ನಡ (Kannada)** across all interfaces.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/darshanagadaginamath-ctrl/dharwad_krishi.git
cd dharwad_krishi

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📦 Deployment on Vercel

This repository includes a pre-configured `vercel.json`:
1. Push this repository to your GitHub account: `https://github.com/darshanagadaginamath-ctrl/dharwad_krishi.git`
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the `dharwad_krishi` repository.
4. Framework Preset: **Vite** (Build command: `npm run build`, Output directory: `dist`).
5. Click **Deploy**!
